## 시작하기

1. [최신 공식 배포](https://github.com/AaronFeng753/Waifu2x-Extension-GUI/releases/latest)를 다운로드합니다.
2. **Additional settings → Compatibility test**에서 사용 가능한 처리 엔진을 확인합니다.
3. **Home**에서 입력 파일·배율·출력 위치를 정합니다.
4. **Engine settings**에서 확대 엔진을 선택하고, **Video settings**에서 필요하면 프레임 보간과 인코딩 설정을 조정합니다.
5. 짧은 샘플을 먼저 처리해 결과를 검증합니다.

⚠️ **Replace original file**, **Delete original files**, **Overwrite**는 원본이나 이전 결과를 삭제할 수 있으므로 테스트 시 해제하세요.

## 문서의 기준

공식 README와 공개된 `SRC_v3.41.01-beta/Waifu2x-Extension-QT/mainwindow.ui`의 옵션·툴팁을 참고했습니다. 최신 실행 파일의 실제 모든 설정과 일치한다고 보장할 수 없으므로 버전별 차이는 추가 확인이 필요합니다.

이 저장소는 원본 프로젝트의 Fork이며, 한국어 문서는 독립적으로 관리합니다.
